# Практические работы по параллельному программированию

Java, группа 24-по-1.

- `practice1`: численное интегрирование.
- `practice2`: обедающие философы.
- `practice3`: множество Мандельброта, динамическая раздача строк потокам.
- `practice4`: сравнение ThreadPerTask, RoundRobin, WorkStealing и FixedThreadPool.

В новых папках находятся исходники, запускаемые JAR, PDF-отчёты и инструкции.
JAR требуют Java 17 или новее. Никаких внешних Java-библиотек не требуется.

Сборка новых работ из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипты ищут Java в `JAVA_HOME`, `PATH` и `%USERPROFILE%\.jdks`.
На компьютере автора используется портативный Temurin из `.jdks`.
`-ExecutionPolicy Bypass` действует только для запущенного процесса PowerShell.

Исходные файлы из Telegram не изменяются. Обе новые реализации написаны отдельно:
в ДЗ3 динамическое распределение строк вместо постоянных блоков, в ДЗ4 учёт
незавершённых задач вместо завершающих маркеров и воспроизводимый стенд замеров.
